# DataLens
Upload a CSV and get instant data analysis.

## Features
- Summary statistics
- Missing value check
- Histogram chart
- Correlation matrix
- JSON report download

## Run method
```
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000 and upload `sample_data/iris_small.csv`.

## Tests
```
pytest
```
